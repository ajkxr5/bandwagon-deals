## 优惠码怎么用？“循环折扣”是什么

等新码出现时，操作只有一步：选好套餐进入购物车结账页，找到 Promotional Code 输入框，粘贴优惠码，点 Validate Code。页面刷新后能看到折扣金额单独列出来，就说明生效了；提示过期就换码或直接购买，没有第三种结果。

真正值得记住的是搬瓦工优惠码的一个特性：**循环折扣**。下单时用了码，之后每次续费会自动按折后价出账单，不需要重新输入，相当于把折扣锁定到你不续费为止。以 11% 的码加 $169.99 年付的 CN2 GIA-E 为例，首年实付约 $151，之后每年续费都是这个价。

这就是老玩家总说“下单前一定先找码”的原因——错过的不是一次优惠，而是未来每一次续费。现在常规码没了，这个习惯暂时用不上，但大促窗口来临时它又会变得很值钱。
